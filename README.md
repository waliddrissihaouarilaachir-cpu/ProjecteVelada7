# La Velada del Año VII - Lloc Web Oficial

Aquest projecte és una aplicació web multi-pàgina desenvolupada com a projecte acadèmic per a la promoció, gestió d'informació i venda d'entrades de l'esdeveniment **"La Velada del Año VII"**.

## Estructura del projecte

* `index.html`: Pàgina principal amb la presentació de l'esdeveniment i un comptador enrere en temps real fins a la data de la gala.
* `combats.html`: Cartellera oficial amb els enfrontaments de la vetllada, horaris i perfils dels participants.
* `entrades.html`: Secció de reserva amb formulari interactiu i calculadora dinàmica de preus segons la zona i la quantitat d'entrades.
* `faq.html`: Resolució de preguntes freqüents organitzada mitjançant desplegables interactius.
* `css/styles.css`: Full d'estils global amb paleta de colors fosca, disseny responsive (Flexbox i CSS Grid) i estils corporatius.
* `js/main.js`: Lògica en JavaScript per al temporitzador en directe, càlcul automàtic de preus i validació de formularis.
* `img/`: Directori destinat als recursos gràfics i multimèdia del projecte.

## Tecnologies utilitzades

* **HTML5:** Estructura semàntica i gràfics vectorials integrats (logotip SVG).
* **CSS3:** Maquetació adaptativa amb Flexbox, Grid i variables de color.
* **JavaScript (Vanilla):** Manipulació del DOM i interactivitat sense dependències externes.

## Instruccions d'execució

1. Descarrega o clona aquest repositori al teu ordinador.
2. Obre la carpeta `proyecto-lavelada` amb Visual Studio Code o qualsevol editor de codi.
3. Executa el fitxer `index.html` directament en qualsevol navegador web modern (Chrome, Edge, Firefox) o mitjançant l'extensió *Live Server*.
